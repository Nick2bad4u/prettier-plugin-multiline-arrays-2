# Security Policy

## Supported Versions

Security fixes are provided for the latest release in the current major line.

| Version | Supported |
| ------- | --------- |
| 6.x     | Yes       |
| < 6.0   | No        |

Update to the latest published version before reporting an issue that may
already be fixed.

## Reporting a Vulnerability

Do not open a public issue or pull request for a suspected vulnerability.
Instead, use [GitHub private vulnerability reporting](https://github.com/Nick2bad4u/prettier-plugin-multiline-arrays-2/security/advisories/new).

Include the affected version, a minimal reproduction, the expected security
impact, and any known mitigations. Reports should avoid real secrets and
sensitive data.

The maintainer will aim to acknowledge a report within five business days and
provide a status update at least every seven days while the report remains
active. Valid reports will be coordinated through the private advisory until a
fix or mitigation is available. Release timing depends on severity,
reproducibility, and compatibility risk.

## Scope

Reports about the plugin's installed runtime, parsing or printing behavior,
published package contents, and release integrity are in scope. Vulnerabilities
in development-only tools should be reported to their upstream projects unless
this repository's configuration makes them exploitable here.
